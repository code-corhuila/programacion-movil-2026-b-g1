# ICA Frontend

Frontend de Ice Cream App (ICA) desarrollado con Ionic React.

## Requisitos

- Node.js instalado.
- Backend Express de ICA ejecutándose en `http://localhost:3000`.

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

La aplicación se abrirá en `http://localhost:5173`.

## Funcionalidades

- Lista de helados mediante `fetch` y `GET`.
- Formulario para crear un helado mediante `POST`.
- Estado de la interfaz con `useState`.
- Manejo de errores de red.
- Navegación a una pantalla de detalle.
