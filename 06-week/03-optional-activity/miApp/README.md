# Semana 06 - Primer proyecto Ionic React

## Descripción

En esta actividad se realizó la configuración del entorno de desarrollo para crear una aplicación móvil utilizando Ionic React.

## Configuración del entorno

Se instaló y configuró:

- Node.js LTS
- Ionic CLI
- Ionic React

## Creación del proyecto

Se creó el proyecto utilizando:

ionic start miApp blank --type=react

## Ejecución de la aplicación

Para ejecutar la aplicación se utilizó:

ionic serve

La aplicación se ejecutó correctamente en http://localhost:8100.

## Modificación de la pantalla inicial

El título inicial "Blank" fue cambiado por:

**Mi primera aplicación móvil**

La modificación se realizó en:

src/pages/Home.tsx

## Evidencia

Se realizó una captura de pantalla de la aplicación ejecutándose en el navegador, mostrando el título "Mi primera aplicación móvil".

## Resultado

El proyecto Ionic React fue creado, ejecutado y modificado correctamente de acuerdo con los requerimientos de la actividad.
