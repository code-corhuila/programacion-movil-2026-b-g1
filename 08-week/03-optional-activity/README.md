## Diferencias entre Kotlin y TypeScript

1. Kotlin es un lenguaje de programación desarrollado principalmente para aplicaciones Android y también puede utilizarse en otros entornos. TypeScript es un lenguaje basado en JavaScript utilizado principalmente para desarrollar aplicaciones web.

2. Kotlin tiene null-safety integrada en el lenguaje mediante tipos anulables como `String?`, mientras que TypeScript permite comprobar valores `null` y `undefined` mediante opciones como `strictNullChecks`.
